# 🛡️ GUI для проверки системы на вирусы с помощью rkhunter

Скрипт `rkhunter-gui.py` предоставляет удобный графический интерфейс (PyQt5) для проверки системы на наличие rootkit'ов и подозрительных файлов с помощью утилиты **rkhunter**.

## 📋 Возможности

- Графическое окно с двумя режимами работы:
  - **Обычный** — 2 кнопки (обновить и проверить / показать отчёт).
  - **Расширенный** — 4 кнопки (полный набор действий).
- Проверка зависимостей (`rkhunter`) с выводом сообщения об установке.
- Предупреждение при запуске **не под root** (rkhunter может не работать).
- Прогресс-бар с состояниями: «Выполняется…», «Проверка пройдена», «Обнаружены предупреждения».
- Встроенная консоль с цветным выводом процесса в реальном времени.
- Сохранение отчёта в лог-файл.
- Разбор отчёта rkhunter: подсчёт подозрительных строк, группировка по секциям.
- Наглядное отображение результата:
  - зелёное сообщение «✔ Проверка прошла успешно»;
  - красное предупреждение «⚠ Обнаружены предупреждения» с количеством находок и путём к отчёту.
- Просмотр последнего отчёта в отдельном окне.
- Подтверждение прерывания при закрытии во время выполнения операции.

## 📦 Зависимости

| Пакет      | Назначение                          | Установка                     |
|------------|-------------------------------------|-------------------------------|
| `python3-pyqt5` | Графический интерфейс (PyQt5)  | `sudo apt install python3-pyqt5` |
| `rkhunter` | Сканер rootkit'ов                   | `sudo apt install rkhunter`   |
| `sudo`     | Запуск проверки с правами root      | уже установлен в системе      |

> **Важно:** скрипт использует PyQt5 и **не требует** `zenity` (в отличие от bash-версии).

## 🚀 Использование

```bash
sudo ./rkhunter-gui.py            # обычный режим (2 кнопки)
sudo ./rkhunter-gui.py -a         # расширенный режим (4 кнопки)
sudo ./rkhunter-gui.py --advanced # расширенный режим (4 кнопки)
sudo ./rkhunter-gui.py -h         # справка
```

### Аргументы командной строки

| Аргумент         | Описание                        |
|------------------|---------------------------------|
| `-a`, `--advanced` | Расширенное меню (4 кнопки)   |
| `-h`, `--help`     | Показать справку и выйти      |
| без аргументов     | Обычное меню (2 кнопки)       |

## 🖱️ Кнопки меню

### Обычный режим (2 кнопки)

- **🔍 Обновить и проверить** — проверка версии (`--versioncheck`), обновление базы (`--update`) и запуск полной проверки (`--check`).
- **📄 Показать отчёт** — открывает последний отчёт в отдельном окне.

### Расширенный режим (4 кнопки)

- **🔍 Обновить и проверить** — проверка версии + обновление базы + полная проверка.
- **✅ Только проверить** — запуск проверки без обновления.
- **🔄 Только обновить** — обновление антивирусной базы без проверки.
- **📄 Показать отчёт** — открытие последнего отчёта.

## Пути и переменные

| Переменная | Значение по умолчанию          | Описание                          |
|------------|--------------------------------|-----------------------------------|
| `LOG_PATH` | `$HOME/antivirus-report.log`   | Путь к файлу отчёта               |
| `REAL_HOME`| домашний каталог SUDO_USER     | Определяется автоматически        |

> Домашний каталог и UID/GID определяются через `SUDO_USER` (или `USER`), чтобы отчёт сохранялся в каталоге реального пользователя, а не root. После проверки владелец лог-файла меняется на реального пользователя (`os.chown`).

## 🔧 Как это работает

1. **Разбор аргументов** — определяется режим работы (обычный/расширенный).
2. **Определение пользователя** — `detect_real_user_and_home()` возвращает `REAL_USER`, `REAL_HOME`, `REAL_UID`, `REAL_GID`.
3. **Проверка зависимостей** — если `rkhunter` не найден (`shutil.which`), выводится сообщение с командой установки.
4. **Предупреждение о root** — если `os.geteuid() != 0`, в консоль выводится предупреждение.
5. **Запуск команд** — через `QProcess` (обёртка `CommandRunner`):
   - вывод читается построчно и транслируется в консоль;
   - по завершении вызывается callback с кодом возврата.
6. **Обновление и проверка** — последовательность:
   ```
   rkhunter --versioncheck
   rkhunter --update
   rkhunter --check --skip-keypress --report-warnings-only --logfile "$LOG_PATH"
   ```
7. **Разбор отчёта** — функция `parse_rkhunter_report()`:
   - проходит по строкам лога, извлекает статусы `[...]`;
   - всё, что **не** входит в `{ok, not found, none found, skipped, whitelisted}`, считается подозрительным;
   - отдельно обрабатывает текстовые `Warning` и финальную секцию `Warnings`.
8. **Итог** — при наличии находок выводится предупреждение с количеством и открывается отчёт; иначе — сообщение об успехе.
9. **Права на лог-файл** — передаются реальному пользователю (`os.chown`).

## ⚠️ Важные замечания

- Скрипт **требует прав root** для запуска `rkhunter` — запускайте через `sudo`.
- Пароль sudo **не запрашивается внутри GUI** — он должен быть введён при запуске скрипта через `sudo`.
- Флаг `--skip-keypress` отключает интерактивные паузы rkhunter, что необходимо для работы в неинтерактивном режиме.
- Флаг `--report-warnings-only` выводит в лог только предупреждения.
- При первом запуске rkhunter может потребовать инициализации базы:
  ```
  sudo rkhunter --propupd
  ```
  Это можно сделать вручную перед первым использованием скрипта.
- Лог-файл по умолчанию создаётся в домашнем каталоге реального пользователя — убедитесь, что каталог существует и доступен для записи (после `chown`).
- Закрытие окна во время выполнения операции требует подтверждения; при подтверждении процесс `rkhunter` будет убит (`QProcess.kill`).

## 🛠️ Решение проблем

| Проблема | Решение |
|---|---|
| «rkhunter не установлен» | `sudo apt install rkhunter` |
| «PyQt5 не установлен» | `sudo apt install python3-pyqt5` |
| Предупреждение «Скрипт запущен не под root» | Запустите через `sudo ./rkhunter-gui.py` |
| Отчёт не найден | Сначала выполните проверку — лог создастся автоматически |
| rkhunter предупреждает о файлах | Просмотрите отчёт, при необходимости обновите базу: `sudo rkhunter --propupd` |
| Ошибка `chown не удался` | Проверьте права на каталог `$HOME` реального пользователя |
