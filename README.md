# 🛡️ GUI для проверки  системы на вирусы с помощью rkhunter

Скрипт `antivirus.sh` предоставляет удобный графический интерфейс (Zenity) для проверки
системы на наличие rootkit'ов и подозрительных файлов с помощью утилиты **rkhunter**.

## 📋 Возможности

- Графическое меню с двумя режимами работы:
  - **Обычный** — 2 пункта (обновить и проверить / показать отчёт).
  - **Расширенный** — 4 пункта (полный набор действий).
- Запрос пароля sudo через диалоговое окно Zenity.
- Автоматическая проверка зависимостей (`zenity`, `rkhunter`).
- Прогресс-бар при обновлении базы и сканировании системы.
- Сохранение отчёта в лог-файл.
- Наглядное отображение результата: зелёное сообщение «✔ Проверка прошла успешно»
  или красное предупреждение «⚠ Обнаружены предупреждения» с подробностями.

## 📦 Зависимости

| Пакет      | Назначение                  | Установка                     |
|------------|-----------------------------|-------------------------------|
| `zenity`   | Графические диалоги         | `sudo apt install zenity`     |
| `rkhunter` | Сканер rootkit'ов           | `sudo apt install rkhunter`   |
| `sudo`     | Запуск проверки с правами root | уже установлен в системе   |

## 🚀 Использование

```bash
./antivirus.sh            # обычный режим (2 пункта)
./antivirus.sh -a         # расширенный режим (4 пункта)
./antivirus.sh --advanced # расширенный режим (4 пункта)
./antivirus.sh -h         # справка
```
Аргументы командной строки
Аргумент  Описание
-a, --advanced  Расширенное меню (4 пункта)
-h, --help  Показать справку и выйти
без аргументов  Обычное меню (2 пункта)


🖱️ Пункты меню
Обычный режим (2 пункта)
🔍 Обновить и проверить — обновляет антивирусную базу и запускает полную проверку.

📄 Показать отчёт — открывает последний отчёт в окне Zenity.


Расширенный режим (4 пункта)
🔍 Обновить и проверить — обновление базы + полная проверка.

✅ Только проверить — запуск проверки без обновления.

🔄 Только обновить — обновление антивирусной базы без проверки.

📄 Показать отчёт — открытие последнего отчёта.

## 🔧 Как это работает
Разбор аргументов — определяется режим работы (обычный/расширенный).

Проверка зависимостей — если zenity или rkhunter не установлены,
выводится сообщение с командой установки.

Проверка sudo — если пароль не закеширован, запрашивается через zenity --password
и валидируется командой sudo -S -v.

Функция Update() — последовательно выполняет:

sudo rkhunter --versioncheck

sudo rkhunter --update
с отображением прогресса в zenity --progress.

Функция Check() — запускает:
```
sudo rkhunter --check --skip-keypress --report-warnings-only --logfile "$LOG"
```
Результат сканирования анализируется.

При наличии предупреждений выводится красное окно с деталями и ссылкой на лог.

При отсутствии — зелёное сообщение об успехе.

Права на лог-файл передаются текущему пользователю (chown).

Функция ShowReport() — открывает лог-файл в zenity --text-info.

Главное меню — бесконечный цикл while true, выход по кнопке «Выход»
или закрытию окна (код возврата ≠ 0).

## ⚠️ Важные замечания
Скрипт требует прав sudo для запуска rkhunter.

Пароль sudo запрашивается один раз и кешируется (sudo -v).

Флаг --skip-keypress отключает интерактивные паузы rkhunter,
что необходимо для работы в неинтерактивном режиме.

Флаг --report-warnings-only выводит в лог только предупреждения.

При первом запуске rkhunter может потребовать инициализации базы:
```
sudo rkhunter --propupd
```
Это можно сделать вручную перед первым использованием скрипта.

Лог-файл по умолчанию создаётся в домашнем каталоге — убедитесь, что каталог
существует и доступен для записи (после chown).



## Проблема  Решение
«Zenity не установлен»  sudo apt install zenity
«rkhunter не установлен»  sudo apt install rkhunter
«Неверный пароль sudo»  Проверьте пароль, повторите запуск
Отчёт не найден Сначала выполните проверку — лог создастся автоматически
rkhunter предупреждает о файлах Просмотрите отчёт, при необходимости обновите базу: sudo rkhunter --propupd
